# Assam Ethnomedicine

A comprehensive data repository and analysis project focusing on the traditional medicinal plants of Assam. This project aims to digitize, document, and analyze the rich ethnomedicinal knowledge of the region, utilizing data science techniques for better understanding and preservation.

## 🌟 Features
- **Extensive Database:** Detailed records of traditional medicinal plants and their uses.
- **Data Analysis:** Jupyter notebooks for exploring and visualizing the ethnomedicinal data.
- **Data Export:** Cleaned dataset available in Excel format for further research.

## 🛠️ Tech Stack
- **Analysis:** Python, Jupyter Notebook
- **Data Storage:** Excel (`.xlsx`)

## 📊 Data
The main dataset is available in `V6.xlsx`. You can explore the data analysis and exploratory scripts via the `Ethnobotany.ipynb` notebook.

## 🚀 Getting Started
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Angsumi/Assam_Ethnomedicine.git
   ```
2. **Setup Environment:**
   Install Jupyter and necessary Python data science libraries (like Pandas).
3. **Run Notebook:**
   ```bash
   jupyter notebook Ethnobotany.ipynb
   ```
